# Kumail Abbas — Research & Engineering Portfolio

Responsive single-page personal portfolio, powered by vanilla HTML/CSS/JavaScript.

## Preview
Open `index.html` in a browser. No installation or build step required.

## Publish via GitHub Pages
Create a public GitHub repository, push `index.html` to its root, then enable **Settings → Pages → Deploy from branch**.

## Before publishing
- Replace the placeholder GitHub link (`href="#"`) with your actual GitHub profile.
- Check each company project summary and publicly linked project URL for current availability and disclosure permission.
- Only add publications/repository links once you have made those public.
- Consider adding a headshot and an approved PDF CV.
